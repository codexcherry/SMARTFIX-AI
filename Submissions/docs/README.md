## 🌐 API Endpoints

### Core Query Processing
- `POST /api/v1/query/text` - Text-based troubleshooting
- `POST /api/v1/query/image` - Image-based analysis
- `POST /api/v1/query/logs` - Log file analysis
- `POST /api/v1/query/voice` - Voice command processing

### Smart Assistant
- `POST /api/v1/smart/query` - Network-aware assistant
- `GET /api/v1/smart/status` - Service status monitoring
- `POST /api/v1/smart/offline` - Offline mode processing

### Galaxy Autopilot
- `GET /api/v1/galaxy-autopilot/status` - System status
- `POST /api/v1/galaxy-autopilot/heal` - Process healing request
- `GET /api/v1/galaxy-autopilot/health` - Health metrics
- `GET /api/v1/galaxy-autopilot/actions/history` - Action history

### System Diagnostics
- `POST /api/v1/enhanced/voice/network-diagnostic` - Network testing
- `POST /api/v1/enhanced/voice/system-diagnostic` - System analysis
- `POST /api/v1/enhanced/voice/screen-analysis` - Screen analysis
